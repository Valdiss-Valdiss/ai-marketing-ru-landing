# CRO-анализ посадочной страницы (научный подход)

## Назначение навыка

Выполнение комплексного CRO-анализа (оптимизация коэффициента конверсии) любой посадочной страницы на основе **научных моделей**: MECLABS, LIFT, Fogg Behavior Model, Schwartz Awareness Levels, Cialdini's 7 Principles.

Данный навык производит **поэлементный разбор** страницы с приоритизированными, практически применимыми исправлениями, основанными на психологии поведения пользователя.

## Когда использовать

- Пользователь предоставляет URL лендинга и просит CRO-анализ
- Пользователь запрашивает оптимизацию конверсии
- Пользователь хочет улучшить регистрацию, сбор лидов или продажи
- Запускается командой `/market-ru landing <url>`

## Как выполнить

### Шаг 0: Определение ICP

ICP определяется автоматически:
- Если пользователь указал ICP в команде → используется предоставленный
- Если ICP не указан → используется "generic problem-aware audience"

Примеры ICP: "B2B SaaS, CTO, growth stage", "Малый бизнес, хочет снизить расходы", "E-commerce владельцы магазинов"

**Почему это важно**: Исследование показывает, что "страница для стадии 'Problem Aware' с оффером для 'Most Aware' — критический разрыв в коммуникации" (Schwartz Awareness Levels).

### Шаг 1: Получить контент страницы

Используйте WebFetch или другой доступный метод для получения HTML-контента страницы.

### Шаг 2: Анализ по научным моделям

LLM проводит анализ, применяя следующие научные модели:

#### 2.1. MECLABS Формула конверсии

Фундаментальная формула, разработанная институтом MECLABS:

```
C = (M × 4) + (V × 3) + (I × 2) + (F × 2) + (A × 2)
```

Где:
- **M (Motivation)** — Внутренняя мотивация пользователя (внешний фактор, к=4)
- **V (Value Proposition)** — Сила ценностного предложения (к=3). Оценивается через 4 вектора:
  - Appeal (привлекательность)
  - Exclusivity (эксклюзивность)
  - Credibility (достоверность)
  - Clarity (ясность)
- **I (Incentive)** — Дополнительные стимулы (к=2): бонусы, скидки, urgency
- **F (Friction)** — Трение (к=2): сложность форм, количество полей, когнитивная нагрузка
- **A (Anxiety)** — Тревога (к=2): отсутствие гарантий, политики конфиденциальности

#### 2.2. LIFT Framework

Модель Крис Говарда, выделяющая 6 факторов:

| Фактор | Роль | Описание |
|--------|------|----------|
| Релевантность | Драйвер | Соответствие заголовка ожиданиям аудитории |
| Ясность | Драйвер | Простота языка, отсутствие жаргона, чёткость CTA |
| Срочность | Драйвер | Временные ограничения или дефицит |
| Ценностное предложение | Базис | Соотношение выгод и затрат |
| Тревога | Ингибитор | Отсутствие доверительных сигналов |
| Отвлечение | Ингибитор | Лишние ссылки и элементы, уводящие от цели |

#### 2.3. Fogg Behavior Model

Модель Б.Дж. Фогга:

```
B = M × A × P
```

Где:
- **B (Behavior)** — Поведение (целевое действие)
- **M (Motivation)** — Мотивация
- **A (Ability)** — Способность (простота действия)
- **P (Prompt)** — Триггер

Если мотивация низка → действие должно быть максимально упрощено. Если действие сложное → нужно больше элементов для мотивации и доверия.

#### 2.4. 5 Уровней осознанности (Schwartz)

| Уровень | Описание | Что искать на странице |
|---------|----------|------------------------|
| Unaware | Не знает о проблеме | Истории, статистика, описание симптомов |
| Problem Aware | Знает о боли, не о решении | "Сопереживание" боли, последствия |
| Solution Aware | Ищет варианты | Сравнения, преимущества метода |
| Product Aware | Знаком с брендом | Фичи, доказательства эффективности |
| Most Aware | Готов к покупке | Чёткий оффер, цена, простое оформление |

**Алгоритм**: Сопоставьте ICP с контентом. Если есть разрыв → критическая рекомендация.

#### 2.5. 7 принципов Чалдини

LLM должен искать лингвистические триггеры каждого принципа:

1. **Reciprocity (Взаимность)** — лид-магниты, бесплатные консультации, пробные периоды
2. **Commitment & Consistency** — микро-шаги ("Пройдите тест", "Ответьте на вопрос")
3. **Social Proof** — количество клиентов, отзывы, рейтинги
4. **Authority** — сертификаты, логотипы партнёров, награды
5. **Liking** — человечность тона, юмор, схожесть ценностей
6. **Scarcity** — "Только 24 часа", "Осталось 3 экземпляра"
7. **Unity** — инклюзивный язык ("Мы", "Наше сообщество")

#### 2.6. Gap-анализ (Pain → Solution Mapping)

Алгоритм дедуктивного анализа:

1. **Идентификация** — из ICP выделить ключевые боли (Pain) и цели (Goal)
2. **Верификация** — сопоставить темы с H1-H3 заголовками
3. **Диагностика** — найти "слепые зоны" (боли без решения)
4. **Оптимизация** — сгенерировать гипотезы для недостающих узлов

### Шаг 3: Аудит по 7 секциям

#### Секция 1: Hero (Вес: 25%)

| Элемент | Проверка | Индикатор |
|---------|----------|-----------|
| Headline | До 10 слов, выгода, не функция | Бенефит-драйв |
| Подзаголовок | Раскрывает headline с конкретикой | 4U framework |
| CTA | Над сгибом, контрастный цвет | First impression |
| Trust badges | Над сгибом | Credibility |
| Визуал | Не generic сток | Relevance |

**Алгоритм проверки headline по 4U:**
- Useful: Решает реальную проблему?
- Urgent: Есть причина действовать сейчас?
- Unique: Отличается от конкурентов?
- Ultra-specific: Конкретные числа/факты?

#### Секция 2: Ценностное предложение (Вес: 20%)

- Чёткое "что делает продукт"
- Конкретные результаты
- Отличие от альтернатив (POD)
- Целевая аудитория ясна
- Выгоды квантифицированы

#### Секция 3: Социальное доказательство (Вес: 15%)

**Ранжирование по силе убедительности:**
1. Revenue/результаты ("2.4 млрд обработано")
2. Именованные отзывы с фото, должностью, компанией
3. Узнаваемые логотипы клиентов
4. Кейсы с конкретными результатами
5. Рейтинги и количество отзывов
6. Упоминания в СМИ

**Проверка близости к CTA**: Если в радиусе ~200 символов от CTA нет trust-сигналов → "High Anxiety Zone".

#### Секция 4: Функции и выгоды (Вес: 15%)

**Формула трансляции функции в выгоду:**
```
Bad: "AI-powered аналитика"
Good: "Видите точно какие кампании приносят доход -- AI анализирует ваши данные"
```

#### Секция 5: Обработка возражений (Вес: 10%)

| Возражение | Решение |
|------------|---------|
| Слишком дорого | ROI калькулятор, сравнение, гарантия |
| Не уверен что работает | Кейсы, пробный период, демо |
| Слишком сложно | Онбординг, "начните за 5 минут" |
| Не уверен что нужно | Проблема → стоимость бездействия |
| А если не понравится? | Пробный период, гарантия, отмена |

**Anxiety Reducers**: гарантии, отзывы, сертификаты должны быть рядом с формой.

#### Секция 6: CTA (Вес: 10%)

**Оценка копирайтинга CTA:**
- Слабый: "Отправить", "Узнать больше"
- Средний: "Зарегистрироваться", "Начать"
- Сильный: "Начать мой бесплатный период", "Получить мою скидку"

**First person**: "Начать МОЙ trial" > "Начать ВАШ trial"

#### Секция 7: Футер (Вес: 5%)

- Final CTA
- Контактные данные
- Политика конфиденциальности
- Trust badges повторены

### Шаг 4: Оценка копирайтинга (5 измерений)

| Измерение | 1-10 | Критерий |
|-----------|-------|---------|
| Clarity | Ясность | Понятно за 5 секунд? |
| Urgency | Срочность | Причина действовать сейчас? |
| Specificity | Конкретность | Числа, время, результаты? |
| Proof | Доказательность | Подкреплено фактами? |
| Action Orientation | Направленность | Ведёт к действию? |

### Шаг 5: Аудит форм

| Элемент | Лучшая практика | Влияние |
|---------|-----------------|---------|
| Количество полей | 3-5 макс | -7% за каждое поле |
| Подписи | Над полем или floating | Читаемость |
| Текст кнопки | Ценность, не действие | CTR |
| Валидация | Inline, конкретные ошибки | Завершение |
| Microcopy | "Без обязательств" | Снижение тревоги |

### Шаг 6: Аудит мобильной адаптивности

- CTA в thumb-zone (нижняя половина)
- Текст ≥16px
- Формы удобны для tap
- Нет горизонтального скролла
- Sticky CTA при скролле

### Шаг 7: Генерация A/B тестов

**Шаблон**: "Если мы [ИЗМЕНИМ], тогда [МЕТРИКА] [УЛУЧШИТСЯ], потому что [ПРИЧИНА]."

Примеры:
1. Headline: функциональный vs выгодный с числом
2. CTA: generic vs ценностный
3. Social proof: выше/ниже сгиба
4. Форма: 4 поля vs 2 поля
5. Urgency: с countdown vs без

## Метрики скилла

| Метрика | Описание | Диапазон |
|---------|----------|----------|
| **CRO Score** | Итоговая оценка (MECLABS) | 0-100 |
| **VPI** | Value Proposition Index | 1-10 |
| **SS** | Scannability Score (% при 5-сек просмотре) | 0-100% |
| **TF** | Trust Factor (количество триггеров) | 0-N |
| **RR** | Resonance Rate (% болей ICP закрыто) | 0-100% |

## Генерация отчётов

### Шаг 3a: Проверка Python

1. Проверь доступность Python: `python3 --version`
2. **Если Python доступен** → используй скрипты (приоритетный путь)
3. **Если Python недоступен** → LLM генерирует Markdown и HTML напрямую (fallback)

### Шаг 3b: Генерация отчётов (Python)

```bash
# Генерация Markdown
python3 scripts/generate_landing_md.py <url> [icp]

# Генерация HTML
python3 scripts/generate_landing_html.py <url> [icp]
```

Отчёты сохраняются в:
- `{cwd}/LANDING-CRO-{domain}-{timestamp}.md` — в папку запуска
- `{cwd}/LANDING-CRO-{domain}-{timestamp}.html` — в папку запуска

### Шаг 3c: Fallback (без Python)

Если Python недоступен, LLM генерирует:
1. Markdown-отчёт напрямую (формат как в `examples/example-landing-audit.md`)
2. HTML-отчёт напрямую (формат как в `examples/example-landing-audit.html`)
3. Оба файла сохраняются в текущую директорию

**Важно**: Fallback использует ту же структуру и методологию анализа, просто формат файлов может немного отличаться.

### Требования к findings:
- Каждый finding = конкретный факт с страницы
- Формат: "Найдено: [что найдено]. Проблема: [почему это проблема]. Влияние: [как влияет на конверсию]"

### Требования к fixes:
- Каждый fix = конкретное действие
- Формат: "[Что изменить] на [Как изменить]. Ожидаемый эффект: [конкретное улучшение]"
- Приоритеты: HIGH (быстрая победа), MEDIUM (среднесрочное), LOW (стратегическое)

## Ключевые принципы

1. **Влияние на выручку**: Всегда связывайте рекомендации с revenue impact. "Изменение CTA на контрастный цвет увеличивает клики на 15-30%, что при 1000 пос/мес = +30-60 лидов".

2. **Приоритизация**: Быстрые победы первыми. Усилие/Эффект.

3. **Конкретность**: "Улучшите заголовок" бесполезно. "Измените с 'Добро пожаловать' на 'Сократите CAC на 40% -- CRM для агентств'".

4. **Научная база**: Все рекомендации должны быть основаны на моделях: MECLABS, LIFT, Fogg, Cialdini.

5. **Gap-анализ**: Проверяйте соответствие болей ICP → контент страницы.

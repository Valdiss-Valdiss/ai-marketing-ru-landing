# market-ru-landing

## Твой лендинг теряет клиентов. Узнай где — за 2 минуты.

Средний коэффициент конверсии лендингов — **2-3%**. Подними его до **5%** — и получишь **вдвое больше заявок** без увеличения рекламного бюджета.

**market-ru-landing** — AI-скилл для OpenCode и Claude Code. Вставь ссылку на свой лендинг — и через минуту получишь детальный отчёт с конкретными исправлениями, приоритизированными по влиянию на конверсию.

Бесплатно. Без специалистов. Без ожидания.

---

## Что ты получишь

Скилл анализирует страницу по **5 метрикам** — каждая отвечает на конкретный бизнес-вопрос:

| Метрика | Что показывает | Зачем тебе |
|---------|---------------|------------|
| **CRO Score** (0-100) | Общая готовность страницы конвертировать | Быстрая оценка: «всё ок» или «надо чинить» |
| **LIFT** (0-100%) | Конверсионный потенциал — что двигает, что тормозит | Поймёшь, почему посетители уходят |
| **Scannability** (0-100%) | Читается ли страница за 5 секунд | 55% посетителей уходят, если не поняли за 3 секунды |
| **Trust Factor** | Сила элементов доверия | Без доверия нет заявок — точка |
| **Resonance Rate** (0-100%) | Насколько контент закрывает боли аудитории | Если не бьёт в боль — не продаёт |

## Как это работает

### 1. Вставь ссылку
```
/market-ru-landing https://твой-сайт.ru
```

### 2. Получи отчёт
Через минуту — **3 файла**:
- **Markdown** — для тебя и команды
- **HTML** — красивая страница с визуализацией (можно показать клиенту)
- **JSON** — сырые данные для интеграций

### 3. Исправь по приоритетам
Отчёт даёт **конкретные действия**, а не абстрактные советы:

> ❌ «Улучшите заголовок»
>
> ✅ «Измените заголовок с "Производство окон" на "Установите тёплые окна за 5 дней — гарантия 10 лет". Ожидаемый эффект: +15-25% CTR»

Каждая рекомендация содержит:
- **Что именно** изменить (с текстом до/после)
- **Приоритет** (HIGH / MEDIUM / LOW)
- **Ожидаемый эффект** в процентах

## Установка

Скилл работает и с **OpenCode**, и с **Claude Code**. Установи один раз — используй где угодно.

### Способ 1: npm (рекомендуется)

```bash
npm install -g market-ru-landing
```

**Для OpenCode** — добавь плагин в `opencode.json`:
```json
{
  "plugin": [
    "...existing plugins...",
    "market-ru-landing"
  ]
}
```

Или укажи полный путь к плагину:
```json
{
  "plugin": [
    "...existing plugins...",
    "ПУТЬ_К_NPM/node_modules/market-ru-landing/.opencode/plugins/market-ru-landing.js"
  ]
}
```

Узнать путь к глобальным npm-пакетам:
```bash
npm root -g
```

**Для Claude Code** — после глобальной установки скилл доступен автоматически через `CLAUDE.md` или `install.sh`.

### Способ 2: Claude Code (curl)

```bash
curl -fsSL https://raw.githubusercontent.com/Valdiss-Valdiss/ai-marketing-ru-landing/main/install.sh | bash
```

### Способ 3: Вручную (git clone)

```bash
git clone https://github.com/Valdiss-Valdiss/ai-marketing-ru-landing.git
cd ai-marketing-ru-landing
./install.sh
```

## Методология

Анализ основан на **научных моделях конверсии**, которые используют ведущие CRO-агентства мира:

- **MECLABS** — формула конверсии: C = (M×4) + (V×3) + (I×2) + (F×2) + (A×2)
- **LIFT Framework** — 6 факторов: релевантность, ясность, срочность, ценность, тревога, отвлечение
- **Scannability Score** — 6 блоков: H1, подзаголовок, CTA, структура, визуал, воздух
- **Trust Factor** — 13 типов триггеров доверия с весами
- **Resonance Rate** — анализ соответствия болей аудитории → контенту страницы

## Требования

- [Python 3.x](https://www.python.org/downloads/) — для генерации HTML/Markdown отчётов
- Один из AI-агентов:
  - [OpenCode](https://opencode.ai/) — рекомендуется, бесплатный, без ограничений
  - [Claude Code](https://claude.com/product/claude-code) — альтернатива (могут быть риски блокировки для пользователей из РФ)

> **Важно:** Если Python установлен, агент автоматически использует скрипты для генерации отчётов. Fallback-режим (без Python) — только если Python недоступен.

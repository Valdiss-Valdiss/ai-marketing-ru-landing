### MECLABS Формула конверсии

```
C = M×4 + V×3 + I×2 + F×2 + A×2
8×4 + 8×3 + 7×2 + 5×2 + 4×2 = 72
```

Где:
- **M (Motivation)** — Мотивация: 8/10 — Внутренняя мотивация пользователя. Без мотивации никакой дизайн не сработает.
- **V (Value Proposition)** — Ценностное предложение: 8/10 — Сила обещания продукта. Должно быть уникальным и конкретным.
- **I (Incentive)** — Стимулы: 7/10 — Дополнительные триггеры: бонусы, скидки, urgency. Катализатор действия.
- **F (Friction)** — Трение: 5/10 — Всё, что усложняет действие. Каждое лишнее действие = потерянный клиент.
- **A (Anxiety)** — Тревога: 4/10 — Страх совершить ошибку. Убивает конверсию рядом с CTA.

**Важно:** Оценки M, V, I, F, A — субъективны и основаны на контент-анализе страницы. Для точного расчёта используйте A/B тесты.
